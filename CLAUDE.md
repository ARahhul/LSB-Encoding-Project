# Rules for Claude in this repository

## Branches
- Never pick or invent a branch name. Before making any commit, ask the user
  which branch to use, and wait for their answer.
- Push only to the branch the user named.

## Authorship
- Claude must not appear as an author, committer or contributor.
- Commit as the repository owner: `rahhul <ara23ainds@cmrit.ac.in>`.
- Do not add `Co-Authored-By`, `Claude-Session`, "Generated with Claude Code"
  or any other Claude attribution to commit messages or pull requests.
